# Soumita Ghosh academic website content pack

This folder contains a GitHub Pages academic website content pack prepared for the repository:

`soumitag.github.io`

It is designed to work with the Academic Pages workflow, where you create a repository from the Academic Pages template and then replace the main content/configuration files with the files in this package.

## Fast setup

1. Go to the Academic Pages GitHub repository: `academicpages/academicpages.github.io`.
2. Click **Use this template**.
3. Create a new public repository named exactly: `soumitag.github.io`.
4. Upload or copy the contents of this folder into that repository.
5. In GitHub, go to **Settings → Pages** and confirm the site is being built from the `main` branch.
6. Your website should appear at: `https://soumitag.github.io`.

## Files included

- `_config.yml`: site title, author information, search-engine description, and links.
- `_data/navigation.yml`: top navigation menu.
- `index.md`: homepage.
- `_pages/`: Research, Publications, Talks, Projects, Mentorship, CV, and Contact pages.
- `_publications/`: selected publication records.
- `_talks/`: selected talks and presentations.
- `_portfolio/`: selected project pages.

## Important privacy note

Do **not** upload your raw CCV PDF directly to a public GitHub website. The CCV contains personal details that are not needed for academic job searches. Instead, create a sanitized public CV PDF and place it in the `files/` folder as:

`files/Soumita_Ghosh_CV.pdf`

Then the CV page link will work.
